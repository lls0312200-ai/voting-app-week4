# 구현 검토 — 2026-09-28

## 코드와 운영 관례

- `npm run lint`, `npx tsc --noEmit`, `npm run build` 통과.
- 질문·선택지·마감 시각은 서버에서 검증한다. 생성·삭제는 매 요청마다 운영자 세션을 검사한다. 쓰기 API는 같은 호스트의 브라우저 요청만 허용한다.
- Neon SQL 값은 템플릿 매개변수로 전달한다. 투표 기록의 유일 제약과 단일 SQL 문으로 중복 제출 및 득표수 증가를 처리한다.
- `.env.local`, 로컬 데모 데이터, 빌드 산출물은 Git에서 제외한다. 운영자 비밀번호는 저장소 문서에 싣지 않는다.
- 로컬 JSON 저장소는 단일 서버 체험용이다. 여러 인스턴스와 Vercel에는 Neon이 필요하다. 쿠키 기반 중복 방지는 다른 기기나 쿠키 삭제까지 막지 못한다.

| Vercel 배포 URL | Production 배포 완료, 실제 URL 검증 통과 |

프로덕션 빌드로 실행한 로컬 서버에서 `node tests/smoke.mjs`가 인증, 생성, 투표, 중복, 결과 접근, 0표, 마감, 정리를 통과했다. 실제 브라우저에서는 샘플 투표를 제출하고 결과 화면의 1표·100% 막대와 나머지 0% 막대를 확인했다. 서로 다른 출처의 쓰기 요청은 403으로 거부된다.

Neon을 연결한 로컬 프로덕션 서버와 Vercel 배포 URL 모두에서 `node tests/smoke.mjs`가 통과했다. 배포 브라우저에서도 시연용 투표를 제출해 1표·100%와 0표·0% 막대, 제작자 이름을 확인했다. 시연용 투표 하나는 남겨 두었고 테스트가 만든 투표는 삭제했다.

저장소는 사용자 요청에 따라 비공개다. Vercel CLI 배포이므로 Git push만으로 자동 재배포되지 않는다.

# ADR 0001: 익명 쿠키 투표와 공유 운영자 비밀번호

## 맥락

수업 과제는 동아리 규모의 빠른 투표 앱이다. 개인 계정·회원 관리와 신원 검증을 넣으면 핵심 투표 흐름보다 인증 구현이 커진다. 하지만 같은 브라우저의 반복 제출은 줄여야 하고 투표 생성·삭제는 운영자만 해야 한다.

## 결정

투표자는 계정 없이 참여하며 서버가 만든 무작위 방문자 ID를 HTTP 전용 쿠키로 보관한다. 한 방문자 ID는 한 투표에 한 번만 기록된다. 운영자는 공유 비밀번호로 로그인하고 서명된 1일 세션 쿠키를 사용한다.

## 결과

가입 없이 투표할 수 있지만 쿠키 삭제, 다른 브라우저·기기를 통한 중복을 막지는 못한다. 신원 확인이 필요한 공식 선거에 사용하려면 계정·참여 자격·감사 기록을 별도로 설계해야 한다. 공유 비밀번호는 담당자별 책임을 구분할 수 없으므로 여러 운영자가 생기면 개별 계정으로 바꿔야 한다.
